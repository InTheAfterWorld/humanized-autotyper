feat(vscode): clear the document before typing; stop faking dry-run verification

before_type() now selects all and deletes after the file opens. Quick Open
only switches tabs, so the previous run's text and caret position survive;
since every target starts from an empty Buffer, typing without clearing
splices new content into the old and the read-back diff degrades into a
useless "length differs". Select-all plus Delete avoids the alternative of
walking to EOF and deleting line by line.

Also fixes a tautology: under dry-run, after_type() compared the target
content against the very file it was read from, so the diff always passed.
It now returns ok=None (unverified), machine._run_multi counts those
separately as files_unverified, and the CLI prints them as [SKIP] rather
than [OK]. Reporting them as OK would imply dry-run had verified the files
when not a single key was sent.

Per-file results are now three-state: OK / FAIL / SKIP.

Tests: 42 sanity checks pass (2 new), validate + gui selftest pass,
notepad path unchanged (chars=5506).
