## VSCode 模式：移除 Ctrl+A + Delete 清空动作

用户决定整组删除清空按键（不是只删 Ctrl+A）。理由：Ubuntu 上焦点落到
Nautilus 时 Ctrl+A + Delete 就是「全选 -> 移到回收站」，一次清空整个目录；
而只删 Ctrl+A 会让 Delete 退化成单字符删除，重跑时把文件写坏。

改动：
- modes.py::VSCodeMode.before_type 删除 ex.key_select_all() / ex.delete_key()
  与两次 sleep，日志由 FILE/cleared 改为 FILE/no_clear。
- 行为：首次打开直接打字（光标在开头）；重访仍走 Ctrl+End 续打。
- 副作用（已接受）：重跑有旧内容的文件时新文本插在旧内容前，after_type
  回读长度不符 -> FAIL，但磁盘不丢数据。
- 同步 sanity_check 四个测试（resume_keeps_content、sends_no_clear_keys
  改名自 clears_document、keyboard_rel_to_workspace 的断言反转）。
- README 对应段落改写。

验证：sanity 42 PASS、validate ALL VALIDATION PASSED、
_verify_linux_guard.py 4/4、_verify_preflight_linux.py 4/4。

遗留（未改，范围外）：executor.py 的 key_select_all / delete_key 已无调用方。
